# Getting Started

To start using BlitzBrowser in the cloud, you need to [create an account](https://dashboard.blitzbrowser.com/access-keys). Our free tier is available immediately after signup, no credit card required. You will be able to test our browsers in seconds.

## Create An Access Key

Next, you'll need to [create an access key](https://dashboard.blitzbrowser.com/access-keys). This key is essential for authenticating and connecting to our pool of browsers. It's important to keep your access keys private to prevent unauthorized access.

![Access Key Dashboard](/img/access-keys.webp)

## Connect your framework

Now that you have an account and an access key, you are ready to connect your project to our browsers. BlitzBrowser is designed for straightforward integration with existing projects using Puppeteer, Playwright and any Chrome DevTools Protocol frameworks.

- [Connect Playwright To BlitzBrowser](/docs/cloud/connect-puppeteer-to-blitzbrowser)
- [Connect Playwright To BlitzBrowser](/docs/cloud/connect-playwright-to-blitzbrowser)
